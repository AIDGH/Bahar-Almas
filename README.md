# Bahar Almas Campaign Game

Bahar Almas Campaign Game is a mobile-first browser game inspired by Fruit Ninja. Players sign in with their phone number, slice fried potatoes, chicken fillets, and samosas by swiping across the screen, and compete for the highest score on the leaderboard.

The experience was created as an interactive campaign landing page and is designed to work across mobile, tablet, and desktop devices.

## Languages and Technologies

- TypeScript
- React
- Next.js
- NestJS
- PostgreSQL
- Prisma
- HTML5 Canvas
- CSS
